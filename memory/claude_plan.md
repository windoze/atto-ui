# 执行计划

本文件记录本次调用的可执行计划与进度。内容只包含可检查的计划、决策和结果摘要，不记录私有推理过程。

## 初始计划

1. 读取 `TODO.md`，找出标题未以 `[DONE]` 开头的第一个任务。
2. 只检查最新提交中是否有与该任务直接相关的未完成事项。
3. 阅读该任务正文、依赖、验证要求和完成记录要求。
4. 检查该任务涉及的代码与测试。
5. 按任务原要求完成实现或审阅，不缩窄范围，不引入 workaround。
6. 如遇到阻塞 spec 正确实现的具体问题，更新 `TODO.md` 加入最小前置任务，保持当前任务未完成，提交后停止。
7. 按顺序运行验证：`cargo fmt`、`cargo clippy --workspace --all-targets -- -D warnings`、任务要求的相关或全量测试。
8. 对任何未排期的测试或 fixture 失败进行修复，或在完成当前任务前明确排入 `TODO.md`。
9. 完成后在 `TODO.md` 中给任务标题加 `[DONE]`，并更新完成记录。
10. 使用清晰的任务提交信息提交本次变更，然后停止，不进入下一个任务。
